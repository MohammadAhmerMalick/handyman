# Languages

How to edit a translation, add a language, or remove one. Business facts stay in `AGENTS.md`. Translator tone and field shape stay in `tmp/i18n/BRIEF.md` and `tmp/i18n/UI-BRIEF.md`.

`tmp/i18n/` is required tooling for the next translation pass. It is not a disposable scratch folder. It holds the English catalogue extract, the two translator briefs, and the extract, validate, and registry scripts.

English is the source locale. It has no URL prefix. Other locales use `/{locale}/...`.

## Where copy lives

A locale is wired in several places. TypeScript catches a missing key in `Record<AppLocale, …>`. It does not catch a missing JSON file, a missing CSS `lang` rule, or the hardcoded list in `generate-registry.mjs`.

| Piece | Path | Role |
| --- | --- | --- |
| Locale list | `src/i18n/routing.ts` | `locales` is the source of `AppLocale`. `defaultLocale` is `en`. `localePrefix` is `as-needed`. |
| Locale metadata | `src/i18n/locales.ts` | RTL set, Open Graph locale, `hreflang`, and font class. Each map is `Record<AppLocale, …>`. |
| UI messages | `messages/<locale>.json` | Loaded by `src/i18n/request.ts`. English source is `messages/en.json`. |
| Catalogue overlays | `src/data/services/i18n/<locale>/<category>.json` | Translated service fields, merged over the English seeds in `src/data/services/index.ts`. English has no overlay folder. |
| Overlay registry | `src/data/services/i18n/registry.ts` | Generated. Do not edit by hand. |
| Sentence templates | `src/data/services/copy.ts` | Per-locale `facts` and `helpers`. These wrap overlay fields into page sentences. They are TypeScript, so the JSON validators never see them. |
| Fonts | `src/app/[locale]/layout.tsx`, `src/app/globals.css` | `next/font` loads Noto families. `html[lang="…"]` in `globals.css` switches `--font-sans` and `--font-heading`. |
| Language names | `messages/<locale>.json` → `LocaleSwitcher` | The switcher reads `routing.locales` and looks up `t(locale)`. Every message file needs a label for every locale, written in that language’s own script. |

`tmp/i18n/generate-registry.mjs` keeps its own locale array (`ar`, `ur`, `hi`, `zh`, `fr`). It does not read `routing.ts`. English is omitted on purpose.

## Scripts

Run these from the repo root.

```bash
node tmp/i18n/extract.mjs
node tmp/i18n/validate-messages.mjs <locale>
node tmp/i18n/validate.mjs <locale> [category ...]
node tmp/i18n/generate-registry.mjs
```

- `extract.mjs` reads `src/data/services/catalog/*.ts` and writes `tmp/i18n/source/<category>.json`. Run it after the English catalogue text or the set of categories changes, before validating overlays.
- `validate-messages.mjs` compares `messages/<locale>.json` to `messages/en.json` (same keys, same array lengths, same `{placeholder}` tokens).
- `validate.mjs` compares one locale’s overlay files to `tmp/i18n/source/`. It checks slugs, fields, and array lengths. A string left identical to English is a warning.
- `generate-registry.mjs` rewrites `registry.ts` from the overlay JSON files that exist. Run it when a locale folder or a category file is added or removed. Editing a string inside an existing JSON file does not require a new registry.

`registry.ts` skips a category file that is missing, so a half-finished locale still generates. `validate.mjs` is what reports the gap.

## Edit an existing translation

UI string:

1. Change `messages/en.json` first when the English text or the key shape changes, then update every other `messages/<locale>.json`.
2. Keep `{placeholder}` tokens and ICU plural shape. Rules are in `tmp/i18n/UI-BRIEF.md`.
3. Run `node tmp/i18n/validate-messages.mjs <locale>` for each locale you touched. Fix every error.

Catalogue entry:

1. Change the English seed in `src/data/services/catalog/` when the English text changes.
2. Run `node tmp/i18n/extract.mjs` so `tmp/i18n/source/` matches the seeds.
3. Update `src/data/services/i18n/<locale>/<category>.json` for each locale. Same slugs, fields, and array lengths. Field shape is in `tmp/i18n/BRIEF.md`.
4. Run `node tmp/i18n/validate.mjs <locale>` for each locale.
5. If a template sentence in `src/data/services/copy.ts` no longer fits the field, update that locale’s helpers in the same pass.

## Add a language

1. Add the code to `locales` in `src/i18n/routing.ts`. Use a short code (`de`, `ru`). English stays the default.
2. Fill every map in `src/i18n/locales.ts`: `ogLocales`, `hrefLangTags`, `localeFontClass`. Add the code to `rtlLocales` only when the language is right-to-left.
3. Add the same code to the `locales` array in `tmp/i18n/generate-registry.mjs`.
4. Copy `messages/en.json` to `messages/<locale>.json` and translate it. Add a `LocaleSwitcher.<locale>` label, in that language’s own script, to **every** `messages/*.json` file (including English). Follow `tmp/i18n/UI-BRIEF.md`.
5. Run `node tmp/i18n/extract.mjs` if `tmp/i18n/source/` is missing or stale. Copy each source file to `src/data/services/i18n/<locale>/<category>.json` and translate it. Follow `tmp/i18n/BRIEF.md`.
6. Add `facts` and a helpers function for the locale in `src/data/services/copy.ts`, and register both on the `facts` and `helpers` records.
7. If the script needs a font that is not already loaded, add it with `next/font` in `src/app/[locale]/layout.tsx` and a `html[lang="<locale>"]` rule in `src/app/globals.css`. Latin languages reuse Outfit and Bricolage Grotesque. Arabic and Urdu share Noto Sans Arabic. Hindi uses Noto Sans Devanagari. Chinese uses Noto Sans SC.
8. Run `node tmp/i18n/validate-messages.mjs <locale>` and `node tmp/i18n/validate.mjs <locale>`. Then run `node tmp/i18n/generate-registry.mjs`.
9. Check `pnpm` typecheck. `Record<AppLocale, …>` fails until `locales.ts` and `copy.ts` both include the new code.

Routes, the locale switcher, `hreflang`, and static params follow `routing.locales`. They do not need a separate list.

## Remove a language

Do not remove `en`.

1. Remove the code from `src/i18n/routing.ts`, from every map in `src/i18n/locales.ts`, and from `rtlLocales` if it was there.
2. Remove it from the `locales` array in `tmp/i18n/generate-registry.mjs`.
3. Delete `messages/<locale>.json`, `src/data/services/i18n/<locale>/`, and that locale’s `facts` entry and helpers function in `src/data/services/copy.ts`.
4. Remove `LocaleSwitcher.<locale>` from every remaining `messages/*.json`.
5. Remove a `html[lang="…"]` rule and a `next/font` loader only when no remaining locale uses that script.
6. Run `node tmp/i18n/generate-registry.mjs`, then typecheck.
